# DzKitab
A marketplace where Algerians buy and sell used books, with photos and offers.

## How to run
Backend: cd dzkitab-backend, create .env from .env.example, npm install, npm run start:dev
Frontend: cd dzkitab-frontend, create .env.local from .env.example, npm install, npm run dev
